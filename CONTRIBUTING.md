# Contributing to Critiquing Islam

Evidence-based corrections, source suggestions and technical improvements are welcome.

## Editorial corrections

Open a [GitHub issue](https://github.com/andrewzaia/critiquing-islam/issues) with the affected page, the precise claim you are challenging, primary references and an explanation of the proposed correction. Indicate whether the issue concerns quotation, translation, context, attribution, historical interpretation or another evidentiary question.

## Research contributions

Proposed articles should:

1. State the question being tested.
2. Cite the primary texts directly, not summaries of their contents by other commentators.
3. Distinguish direct textual evidence from historical inference.
4. Consider serious alternative interpretations without artificially equalising evidence.
5. State conclusions proportionate to their supporting material.

Original writing is expected. Do not submit unlicensed transcripts or copied articles.

## Technical changes

Build and validate before submitting changes:

```sh
npm run check
npm run build
```

Please keep changes focused, accessible, responsive and compatible with Cloudflare Pages. Each pull request should describe what changed and how it was tested.

## Conduct

Disagreement about religious ideas is welcome. Threats, harassment, dehumanisation and personal attacks are not.
